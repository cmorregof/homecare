# Dataset Access

Protected clinical datasets required for future CARMEN-Forecast evaluation must be accessed through their official approval pathways.

Repository policy:

- This repository may store dataset documentation, schemas, and loader stubs.
- This repository must not store restricted raw tables, derived identifiable data, or unapproved exports.
- Access approvals, user agreements, and local storage controls remain the responsibility of the authorized research team.

The synthetic dataset bundled with this module is intentionally limited to local software testing and should never be described as a substitute for real validation.
